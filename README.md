# EE459 USC Capstone Project: Biometric Synthesizer

Repository containing the source code and project report for Team 32's Capstone Project for EE459x Embedded Systems Laboratory Spring 2026.

## [Project Report](./Biometric_Synth_Report.pdf)

## Directory Structure
### `/src/`
Contains the source fils for the main control loop (`main.c`) and supporting modules (e.g. `adc_read.c`, `spi_display.c`, and `midi_ouptut.c`)

### `/debug/`
Contains debug scripts used for component testing during development.

### `/misc/`
Contains standalone testing and lab scripts used to get familiar with and test the functionality of our core components (e.g. at328 mcu and oscillator)
